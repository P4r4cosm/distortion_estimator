# Программный комплекс параметрической идентификации аудиоэффектов

![Python](https://img.shields.io/badge/Python-3.13%2B-blue)
![PyTorch](https://img.shields.io/badge/PyTorch-2.0%2B-ee4c2c)
![Gradio](https://img.shields.io/badge/UI-Gradio-ff7c00)

Данный репозиторий содержит исходный код программного комплекса, разработанного в рамках выпускной квалификационной работы (ВКР). Проект посвящен автоматическому определению (идентификации) параметров гитарных VST-плагинов на основе методов глубокого машинного обучения и парадигмы «Анализа через синтез» (Analysis-by-Synthesis).

## Аннотация
Система принимает на вход необработанный инструментальный сигнал (Dry) и обработанный целевой сигнал (Wet), после чего извлекает спектральные характеристики (Mel-спектрограммы) и вычисляет конфигурацию ручек управления эффектом (Distortion, Tone, Level). 

В основе вычислительного ядра лежат две архитектуры нейронных сетей:
1. **Distortion2DNet** — базовая сверточная модель для регрессии параметров.
2. **SiameseParamEstimator** — продвинутая модель на базе сиамских сетей (Siamese Networks) с механизмом внимания (Attention) для высокоточного попарного анализа аудио-тензоров.

## Ключевые особенности
* **Аппаратная оптимизация (CPU Inference):** Благодаря использованию блокировок градиента (`torch.no_grad()`) и легковесной архитектуре, инференс системы оптимизирован для работы на центральных процессорах (~0.08 сек/запрос) и не требует наличия дискретной видеокарты (GPU) у конечного пользователя.
* **Интеграция с VST-хостами:** Программный рендеринг предсказанных параметров осуществляется в реальном времени через библиотеку `pedalboard`, выступающую в роли VST-хоста.
* **Асинхронная аналитика:** Графический интерфейс оснащен модулем построения графиков высокой плотности (Plotly) для оценки АЧХ, микродинамики и RMS-огибающей сигнала.

## Системные требования и зависимости

Для корректной работы комплекса требуется:
* Операционная система: Windows 10/11, macOS, Linux.
* Оперативная память (RAM): не менее 8 ГБ.
* **Программный VST-синтезатор:** Для работы функции автоматической генерации целевого сигнала необходим коммерческий VST3-плагин **Brainworx bx_distorange** (или его эквивалент, настроенный в коде). 
  * *Примечание: В связи с лицензионными ограничениями (DMCA), файл `.vst3` не включен в данный репозиторий. Пользователю необходимо самостоятельно поместить легально приобретенную копию плагина в директорию `./vst/bx_distorange.vst3` или указать системный путь к нему в конфигурации сервера.*
